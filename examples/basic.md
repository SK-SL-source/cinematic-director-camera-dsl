# Examples · Basic

Single shots in STRICT mode (the default). The DSL goes in, the validator reports, and each adapter writes its own wording of the **same** camera intent. Every block between `<!-- case -->` markers is real output, regenerated by `python scripts/audit.py --sync`; the audit fails if the output stops matching. `{SUBJECT}` is the slot where your prompt names the person.
