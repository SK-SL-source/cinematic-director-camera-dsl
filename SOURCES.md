# Sources

This skill was written from scratch. The projects below were studied as references: their terminology, structure or published findings informed the rules. No text was copied in, except MiniMax H3's own prompt format, which the H3 wrappers must reproduce for the model to read it.

IDs such as `SRC-004` in the registry, the model notes, the references and the warnings point to this list. Citations such as `research/07 D16` point to the maintainer's design notes, which are kept outside this repository.
