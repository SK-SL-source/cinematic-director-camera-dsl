# Tests · MiniMax H3 routing evidence scope

> Routing reads reality evidence only for the mode + generation profile it is asked about (PROJECT_GOAL.md; CL-032).
> `routing[minimax_h3:profile=<id>]~regex` matches the routing block for that scope, `h3mode=<mode>` gives the mode alone;
> the same tokens work in `warn[]` / `nowarn[]`. Without matching evidence every item is UNVERIFIED and no grade is borrowed
> from another mode or profile. The frozen H3 core snapshot (tests/snapshots/minimax_h3_core.json) is checked by the runner itself.
